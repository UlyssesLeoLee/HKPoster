# FONT-HKP-REV-001｜对抗式自审与未解决问题

- 审核范围：设计文档内部一致性、执行可行性、授权风险
- 注意：未实际构建字体，不能用此报告代替字体测试报告

## 1. 审查发现与修正结果

| 编号 | 级别 | 原风险 | 当前修正 / 余留 |
|---|---|---|---|
| RV-01 | HIGH | 港片风格被“霓虹/旧化”外观取代 | 将字形轮廓与海报后期分离；待单色样张验证 |
| RV-02 | HIGH | 香港题材却以简体作为主基线 | 建议香港繁体优先、简体可选扩展；等待确认 |
| RV-03 | HIGH | 把一个视觉字样当作完整可安装字体 | 对效果图加注概念属性；源字体明确未完成 |
| RV-04 | HIGH | 500/1500 字数字无法核验 | 引入实际字符清单和冻结范围 |
| RV-05 | HIGH | 许可证未定而默认可商用 | 许可证保持 UNDECIDED，发布门禁阻断 |
| RV-06 | MEDIUM | 字形只强调厚、粗，缺少复杂字内白控制 | 增加“龍、義、警”等困难字验收 |
| RV-07 | MEDIUM | 字体表需求不区分轮廓技术 | 真字形阶段再确定 TTF/CFF 与适用表 |
| RV-08 | MEDIUM | UT/IT/ST 只有清单没有结果 | 表格统一 `NOT_RUN`，需证据才能改状态 |

## 2. 需要项目决策的事项

1. 正式发布时，是繁体为主还是简繁双主基线？
2. 500 字标题版与 1,500 字实用版，哪个是首发目标？
3. 是否需要特定香港标准字形/字汇表，以及其权威依据？
4. 字体发行是否采用开放许可证，还是只供自有项目使用？
5. 实际画字流程采用哪种软件/源格式、由谁负责人工审核？

## 3. 最终自审结论

设计文档可作为**制作启动基线**，但未达到**字形/字体发行验收基线**。正式开始批量绘制前，应先完成 Wave 0 代表字形并用单色样张冻结关键比例与端点系统。
