## 2. 需要项目决策的事项

1. 正式发布时，是繁体为主还是简繁双主基线？
2. 500 字标题版与 1,500 字实用版，哪个是首发目标？
3. 是否需要特定香港标准字形/字汇表，以及其权威依据？
4. 字体发行是否采用开放许可证，还是只供自有项目使用？
5. 实际画字流程采用哪种软件/源格式、由谁负责人工审核？

## 3. 最终自审结论

设计文档可作为**制作启动基线**，但未达到**字形/字体发行验收基线**。正式开始批量绘制前，应先完成 Wave 0 代表字形并用单色样张冻结关键比例与端点系统。

### Wave 0 之后的修订结论（2026-10-24）

- **Wave 0 已完成**：12 个代表汉字 + 26 Latin 大写 + 10 数字 + 26 标点共 74 个设计字形，
  工程链路（recipe → UFO → OTF/TTF/WOFF2）可运行、可复现，UT/IT/ST 三套可执行检查 28 PASS / 0 FAIL。
  比例与端点系统已冻结（字面框、权重分层、advance、cap/基线对齐规则）。
- **仍未达到发行基线**，阻断项四条：
  1. 4 个汉字（城、火、夜、風）识别质量不足，需按 `10_Wave0试制记录.md` §7 返工；
  2. 许可证仍为 `UNDECIDED`，发布门禁（G4）继续阻断；
  3. macOS、Linux、浏览器 WOFF2 平台测试 **NOT_RUN**；
  4. Latin 小写、简体衍生与地区变体未开始，`locl` / `palt` / `halt` 仅有预留注释。
- **可以进入 P1（标题高频字）的前置工作**：工程链路与门禁已就位；
  但 P1 的批量绘制应等上述第 1 条的 4 个汉字返工完成、且样张复核通过后再启动。
