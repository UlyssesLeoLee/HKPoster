## 1. 原创性与来源管理

- 可以研究香港电影海报字体的时代特征、块面关系、比例及排版张力。
- 不得直接复制具体影片片名的独创手写字样或既有商业字体的轮廓数据。
- 参考图像、外包字形、现有字体、开源代码应逐项记录来源、许可、修改和使用范围。
- 海报视觉概念图属于**创意效果参考**，不可直接视为合法或工程合格的字形轮廓来源。

## 2. 许可证决策

### 2.1 已拍板（2026-11-10）

**字体二进制采用 SIL Open Font License 1.1**，保留字体名 `HK Poster Heavy`。

- 许可全文 `OFL.txt` 随包发布（逐字节取自 openfontlicense.org，仅填头部版权行与保留字体名，正文未改；sha256 `49972CF0…76AF0`）。
- 声明写进成品字体的 OpenType name 表（nameID 0 / 13 / 14），由 `build_font.py` 的 `apply_license_notice()` 在 build 阶段注入。
- **源工程代码另按仓库根 `LICENSE`（GNU GPL v3）授权** —— 字体二进制与源代码是两个不同的授权客体，不要混为一谈。

### 2.2 遗留：OFL 与 APL 的条款张力（据实记录）

自动骨架层 7246 字派生自 `hanzi-writer-data`，受 **APL** 约束：

| 条款 | 状态 |
|---|---|
| §1 原样保留 `ARPHICPL.TXT` | ✅ 随包 |
| §2(a) 显著声明修改 | ✅ `NOTICE.md` + 字体 name 表 |
| §2(b) 修改须自由提供给第三方 | ✅ 完整源码公开于 GitHub |
| §3 / §5 不得附加额外限制 | ⚠ **未解决** —— OFL 要求衍生字体继续以 OFL 分发，与 APL「不得在 APL 之外分发 / 不得施加额外限制」冲突 |

这是**已知且被记录的**条款张力，不是「已彻底解决」。若需法律意见级别的确定性，备选路径：

1. 整款字体改用 **Apache-2.0**（无 copyleft 限制，与 APL 相容性更干净）；
2. 自动层改用许可更宽松或自有产权的数据源；
3. 该层 7246 字逐字重画，彻底脱离 APL。
