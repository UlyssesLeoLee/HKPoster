# FONT-HKP-REL-001｜授权与发布设计

- 发布对象：待实现的字体软件与设计资料
- 当前授权状态：**UNDECIDED（未定）**

## 1. 原创性与来源管理

- 可以研究香港电影海报字体的时代特征、块面关系、比例及排版张力。
- 不得直接复制具体影片片名的独创手写字样或既有商业字体的轮廓数据。
- 参考图像、外包字形、现有字体、开源代码应逐项记录来源、许可、修改和使用范围。
- 海报视觉概念图属于**创意效果参考**，不可直接视为合法或工程合格的字形轮廓来源。

## 2. 许可证决策

在确认全部素材权属及字体构建方式后，选择适当许可。可评估 SIL Open Font License 1.1 或商业自定义许可，但不能在此阶段自动宣称任何授权已经生效。若选择 OFL，需检查 Reserved Font Name 及许可证、版权告知要求。

## 3. 版本管理

建议 `0.1.0` 为概念阶段版本；真实字体首次可发布版本另行批准。每次发布保存：字符覆盖表、字体哈希、构建工具版本、授权文件、变更日志、测试证据及示意样张。
