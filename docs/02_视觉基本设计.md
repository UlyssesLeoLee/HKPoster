# FONT-HKP-BD-VIS-001｜视觉基本设计

- 对应需求：REQ-001、002、004、005
- 状态：设计建议，须通过代表字形试制验证

## 1. 视觉概念

**基因：大字招牌 / 商业动作片标题 / 密集块面 / 手工修形。**

借鉴香港商业电影海报标题的凝聚力，而非复制某一年代海报的颜色、描边或某一影视作品的现成字样。画面即使移除所有后期效果，笔画本身仍应让人感到“厚、紧、猛、稳”。

## 2. 风格编译：形容词 → 构造规则 → 审查证据

| 风格语义 | 字形实现方向 | 证据 / 不通过条件 |
|---|---|---|
| 厚重 | 较高黑白面积比，主笔画尽量保持重量一致 | 复杂字内白过小则失败 |
| 紧凑 | 允许偏窄字面；侧边空间较小但不能碰字 | 连字或并排时不得粘连 |
| 动势 | 少量端点倾切/外沿微伸，不改变汉字骨架 | 不可形成整体不可控倾斜 |
| 戏剧性 | 中宫凝聚、轮廓有拔势和明确顿挫 | 不可让结构朝同方向机械扭曲 |
| 手工感 | 用曲线/角点的人工光学校正替代随机噪声 | 不应带来连续字形的视觉不统一 |
| 港片时代感 | 在表现层适配红黄/霓虹/旧印刷工艺 | 黑白单色版本仍应成立 |

## 3. 视觉参数（初始假设，非实测值）

| 参数 | 起步方向 | 需要验证 |
|---|---|---|
| 字宽 | 正常至轻度 Condensed | “港、龍、義”等字横向挤压是否丢失结构 |
| 字重 | Heavy/Black 视觉级 | 复杂字内白和小字号表现 |
| 端点 | 方切为主，少量斜切 | 端点系统能否贯穿不同部件 |
| 转角 | 外角硬、内角必要时适度开孔 | 印刷和栅格渲染是否堵塞 |
| 重心 | 稳定略低，局部微动态 | 不可因逐字动态产生基线跳动 |
| 负空间 | 在最稠密的部位优先保护识别特征 | 黑白反转、远视和缩印测试 |

不得将字形几何和应用样张中的旧化、荧光、雨夜摄影效果混为一谈。

## 4. 风格偏差和对照组

- **偏差 A：过于普通的无衬线黑体。** 需要有少量合理的非机械切角与外廓张力。
- **偏差 B：过分书法化。** 不做长飞白，不把笔画写成毛笔画的复制品。
- **偏差 C：靠特效“港风化”。** 去掉光效后仍应识别为同一设计家族。
- **偏差 D：过多斜切与碎裂。** 不应妨碍正式文本输出或小字号标题。

## 5. 样张测试组

- 单字：港、影、龍、義、火、夜、城、警、愛、風、無、道。
- 双字：龍城、夜行、江湖、英雄、風暴。
- 四字：英雄本色、旺角風雲、霓虹之夜、黑夜追擊（原创样张组合）。
- 英文：CITY OF SHADOWS、LAST BULLET、1997、HONG KONG。

“英雄本色”属于已有影片名称；在测试样张中仅用来检查排版，不可复制原片名字形或将其作为自有品牌资产。
