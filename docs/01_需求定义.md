# FONT-HKP-SRS-001｜字体需求定义书

- 版本：v1.0
- 状态：设计基线，尚未批准制作
- 对象：一套具有香港电影海报视觉气质的展示用粗体字体

## 1. 目标

以粗重、紧凑、略带手工修整痕迹的字形表达香港商业电影标题的力量感、速度感、戏剧张力。无需依赖描边、霓虹或旧化纹理即可在黑白状态下成立。

## 2. 使用范围

| ID | 优先级 | 需求 | 验收思路 |

| REQ-001 | P0 | 应用于电影/游戏/活动海报的大字号标题 | 48–180 px 样张人工审核 |

| REQ-005 | P0 | 高密度中文仍应可辨认 | 复杂字“義、龍、警、驚”等测试 |

## 3. 视觉风格限制

- **必须：** 厚重、集中、清晰、局部动势、适当手工感、商业宣传张力。
- **不得：** 模仿现有电影的独创片名字形；大面积永久损伤轮廓；以霓虹特效替代字形设计；为追求夸张改变文字辨识所依赖的关键结构。
- **可选：** 斜切端点、局部拔角、适度不对称、视觉修正。

## 4. 首发范围与阶段

| 阶段 | 建议范围 | 交付口径 |
|---|---|---|
| P0 概念验证 | 30–50 个高信息量的汉字/字母样本 | 建立骨架、部件、视觉基准与排版样张 |
| P1 海报字集 | 约 500 个高频标题汉字，加 Latin 基础与标点 | 实际清单冻结后以清单为准，不用数量代替覆盖 |
| P2 生产实用版 | 扩大至约 1,500 个目标汉字及相应字形变体 | 覆盖已批准的用途清单 |
| P3 可选扩展 | 更广繁体/简体/假名、字重/字宽 | 单独评估资源及许可证 |

**边界：** 上述规模是规划选项，尚非已制作字形数量。实际可发布范围以冻结字符清单为准。

## 5. 成功与失败判定

黑白样张上能够体现电影标题气质且不同字形保持统一，是视觉层面的通过前提。成品字体必须满足已冻结字表覆盖、无阻断性结构错误、真实排版和平台测试通过。测试未执行不得标为 PASS。
