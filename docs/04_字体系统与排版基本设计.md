# FONT-HKP-BD-TYP-001｜字体系统与排版基本设计

- 对应需求：REQ-001、004、008、012
- 状态：参数候选，待第一轮字形制作确认

## 1. 家族与命名

首期一款独立静态字重：

- Font Family（建议）：`HK Poster`
- Subfamily（建议）：`Heavy`
- Full Name：`HK Poster Heavy`
- PostScript Name：`HKPoster-Heavy`
- CSS weight（计划）：900

“港映重黑”是暂定中文项目名称，发布时须进行字体家族名称与商标相似性检查。扩展的 Outline 和 Shadow 优先作为排版效果而非新的字体轮廓文件；Condensed 为独立扩展范围。

## 2. 初始度量候选（仅设计占位）

| 字段 | 候选 | 说明 |
|---|---:|---|
| UPM | 1000 | 易于制作和记录，非强制 |
| CJK 方格 advance width | 1000 | 先按全角候选，后续根据字体定位核验 |
| 典型 ascender | +880 | 起点，不是已验证 OS/2 或 hhea 设置 |
| 典型 descender | -120 | 起点，应同实际字形边界和行距设计校准 |
| 行距 | 依目标排版软件测试确定 | 不能简单将海报视觉行距作为字体度量值 |

**注意：** OS/2 `sTypoAscender`、`sTypoDescender`、`usWinAscent`、`usWinDescent`、`hhea` 等应分别依据实际字形边界与目标平台渲染规则设计，不能由以上候选值自动推断为最终合格。

## 3. 字距与排版

- CJK 主标题缺省保持清晰的全角逻辑，紧凑排版优先使用应用侧字距调整，避免字符之间结构粘连。
- 英文标题采用独立 Latin 侧边距和成对微调，重点组合：AV、AW、TA、TO、YA、LT。
- 数字 0–9 需在日期、年份、票房数字等典型标题场景中权重一致。
- 全角与半角标点并行处理；仅在有实际需求时启用 `palt` / `halt` 等特性。
- 如设计纵排，另行制定标点替换及垂直度量方案，不把纵排强制加入初期基线。

## 4. 推荐样张

- 黑白 48/96/192 px 横排样张；红字黑底与黄字红边作为附加效果组。
- 中英数字组合：`龍城風暴 1997 / CITY OF SHADOWS`。
- 标点、负字距、紧密的双行布局；避免以相同标题反复测试而遗漏复杂字符。
