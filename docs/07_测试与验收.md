# FONT-HKP-TST-001｜字体 UT / IT / ST 测试与验收

- 对应需求：REQ-001、002、003、004、005、007、008、012
- 当前状态：**全部 NOT_RUN**（设计文档并非测试报告）
- 详细用例：`../tables/字符集与测试计划.xlsx` 的“测试用例”工作表

## 1. UT｜单体测试

逐字检查实际轮廓闭合、方向、简繁映射、字面、侧边距、基本视觉一致性与复杂字留白。所有 UT 均须以真实制作的源轮廓为输入，不能用海报概念图代替。

## 2. IT｜集成测试

检查 `cmap`、字体家族命名、字形替换、字距、必要的 GPOS/GSUB 功能、中英混排；有多地区字形时执行 locale 变体抽查。有无某特性必须与基本设计中的启用清单一致。

## 3. ST｜系统测试

在目标 Windows/macOS、浏览器、设计软件中安装或加载真实字体；测试纯黑白、纯大字、48/96/192 px、复杂汉字、数字与英文。性能与体积若没有量化目标，应在正式发布前先冻结目标，不声称“符合”未设定的阈值。

## 5. 阻断标准

未经批准的关键缺字、坏轮廓或无法加载、编码错映射、重大字符识别失败、无权使用第三方轮廓/品牌、核心测试未运行，任何一项均阻断正式发布。视觉审查应由至少两类场景样张支持：单色字形和实际海报标题。
