## 1. UT｜单体测试

逐字检查实际轮廓闭合、方向、简繁映射、字面、侧边距、基本视觉一致性与复杂字留白。
所有 UT 均以真实制作的源轮廓为输入，不用海报概念图代替。

**Wave 0 实际执行**（`font-src/tests/test_glyph_metrics.py`，直接读 UFO 源）：

| 检查 | 判定 | 结果 |
|---|---|---|
| 轮廓闭合与自交 | shapely `Polygon.is_valid` | PASS |
| 空字形 | 轮廓点数 < 3 或无有效面积 | PASS |
| em 盒越界 | 横向 ±120、纵向 880/-120 之外 | PASS |
| CJK advance | 必须 = 1000 | PASS |
| Latin 大写 advance / 顶线 | advance = 640；顶线 700 ± 8 | PASS（离散 1 单位） |
| 数字 advance | 必须 = 640 | PASS |
| 重复 Unicode 映射 | 全 master 唯一 | PASS |
| 墨量率离群 | 离同类中位数 > 2.2 倍 | WARN 级信号（见 RV-10） |

另有 `font-src/scripts/check_glyphs.py` 提供同口径的独立检查（`FAIL 0 / WARN 6`，WARN 均为密度离群）。

## 2. IT｜集成测试

检查 `cmap`、字体家族命名、字形替换、字距、必要的 GPOS/GSUB 功能、中英混排；
有多地区字形时执行 locale 变体抽查。有无某特性必须与基本设计中的启用清单一致。

**Wave 0 实际执行**（`font-src/tests/test_opentype.py`）：

| 检查 | 判定 | 结果 |
|---|---|---|
| 必需表 | TTF 12 表 / OTF 11 表齐备 | PASS |
| name 表 | family/subfamily/full name/version/PostScript name | PASS（族名与样式名走排版名 nameID 16/17，见 RV-09） |
| OS/2 与 head 度量 | usWeightClass 900、UPM 1000 | PASS |
| hhea 度量 | ascender 880 / descender -120 | PASS |
| cmap 覆盖 | 每个源字形的 Unicode 都能查到 | PASS（75 项映射，源字形 100% 覆盖） |
| 真实排版 | uharfbuzz 排版不出现 `.notdef` | PASS |
| kerning 生效 | AV/AW/TA/TO/YA/LT 排版推进 < 无 kern 的 advance 之和 | PASS |
| 地区变体 `locl` | 需有第二套地区字形 | **SKIP**（简体衍生未开始） |
| 中英数字混排 | 样张已生成 | PASS |

GSUB 未启用（`locl` / `palt` / `halt` 仅有预留注释，因无对应字形，启用会导致编译失败）。

## 5. 阻断标准

未经批准的关键缺字、坏轮廓或无法加载、编码错映射、重大字符识别失败、
无权使用第三方轮廓/品牌、核心测试未运行，任何一项均阻断正式发布。
视觉审查应由至少两类场景样张支持：单色字形和实际海报标题。
