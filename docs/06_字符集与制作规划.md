# FONT-HKP-CHR-001｜字符集与制作规划

- 对应需求：REQ-003、005、007、010
- 主数据：`../tables/字符集与测试计划.xlsx` 的“字符规划”工作表

## 1. 字符规划基线

按照 **字符 → Unicode 码点 → 对应 glyph → 地区/语言形态 → 制作状态 → 证据** 管理，不仅以字符总量控制范围。当前表是**代表字形与标题高频候选清单**，不能据此声称已覆盖香港繁体或任何编码标准。

## 2. 分批原则

- Wave 0：港、影、龍、義、城、火、夜、風、警、愛、無、道等高信息量代表字，配 Latin 基础字母。
- Wave 1：标题高频字、繁体常用标点、阿拉伯数字、拉丁大写字母；首次可发布规模以冻结后清单为准。
- Wave 2：增加市场常见影视题材字、完整小写 Latin、简体衍生及地区变体。
- Wave 3：进一步扩展汉字与功能，不承诺覆盖所有繁体字符。

## 3. 覆盖计算

字符覆盖率 = 当前批次**已通过实际字形与编码验证的预定 Unicode 字符数** / 当前批次批准范围的 Unicode 字符数。多地区字形属于附加 glyph 和功能覆盖，单独统计，避免因一码多形造成重复计数。

## 4. 缺字策略

未制作字符应明确标为 `NOT_STARTED`，预览或样张若调用系统回退字体必须明确标注；不能将回退字体绘制的字符计入自有字体覆盖率。不得给尚未确认的字形随意指派 Unicode 私用区码点。

## 5. 冻结与变更

冻结字符清单后，新增/删除/更改地区字形需生成变更记录、影响清单和回归测试。设计者可提出“先做 500 字”的建议，但应以实际字符列表而非估计数量验收。
