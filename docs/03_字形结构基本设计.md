# FONT-HKP-BD-GLY-001｜字形结构基本设计

- 对应需求：REQ-002、003、005、006
- 状态：设计方案，参数待试制冻结

## 1. 结构策略

以清晰的正字骨架为基础，依次完成：基础黑体骨架 → 部件统一 → 字面比例调整 → 光学校正 → 海报式端点与转角微修 → 代表字形评审。禁止在字符画完后对所有字做无差别的“挤压/倾斜”处理。

## 2. 字面系统

- 建议 UPM 1000 作为设计起点（由详细设计阶段确认）；中宫和部件净空采用图形实测后冻结。
- 汉字设计使用稳定的字面框，复杂字允许局部拆让，不强求笔画绝对等宽。
- 对“港”：重点保留氵与右侧“巷”的独立识别，控制横向挤压下的左右重量。
- 对“龍”：保护内部多个短笔之间的白空间，必要时局部瘦身而非整体缩细。
- 对“義”：避免层叠横画在印刷缩小时合并，维持上宽下稳的结构关系。
- 对“風”：外框及内部虫部件需形成清晰对比，避免外框过分包裹。

## 3. 轮廓规则

| 规则 ID | 规则 | 例外与处理 |
|---|---|---|
| GLY-001 | 横竖笔画维持统一视觉重量 | 高频交叉和小空腔允许局部减重 |
| GLY-002 | 外角以清晰硬折为主 | 弧形轮廓需光学平滑 |
| GLY-003 | 装饰斜切仅作用于不影响结构的位置 | 汉字关键辨识笔画不允许随意去除 |
| GLY-004 | 同部件保持家族相似性 | 偏旁在左右、上下不同位置需光学校正 |
| GLY-005 | 字间紧凑但不得接触 | 标题排版内相邻字不同内容均须测试 |
| GLY-006 | 缩小后维护负空间 | 小尺寸不得出现内部白块完全消失 |

## 4. 地区字形处理

首发建议以繁体中文（香港视觉习惯）为主；简体中文通过新增字形或相应映射扩展。Unicode 汉字统一编码不等于所有地区的字形必须完全一致；如需要 `locl`，应限定语言系统和对应的字形替换，不把地区版本混入任意字符。IVS 仅在确有正式登记及实现能力时使用。

## 5. 代表字形试制验收

每一代表字形保存：轮廓源文件、单色 48/96/192 px 样张、设计规则 ID、人工审查结果与修改证据。首轮至少覆盖包围、左右、上下、穿插、密集、非对称结构；未试制字形不得视为完成。
