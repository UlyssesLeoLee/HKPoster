# 港映重黑｜香港电影海报风格粗字体设计资料包

**文档基线：v1.0 · 2026-10-24**  
**项目代号：HK Poster Heavy / 港映重黑（暂定名）**  
**交付性质：设计文档及视觉概念，不包含可安装字体。**

本资料包将对话中的香港电影海报风格粗字体方案整理为可用于后续制作的需求、基本设计、详细设计、测试与发布资料。设计将 1980—1990 年代香港商业电影海报的标题张力转化为可执行的字形设计规则，同时避免直接复刻任何具体电影片名字形。

## 阅读顺序

1. `00_完整设计文档.md`：面向设计与项目评审的一体化文档；
2. `docs/01_需求定义.md`：目标、范围与验收口径；
3. `docs/02_视觉基本设计.md`、`03_字形结构基本设计.md`、`04_字体系统与排版基本设计.md`：视觉系统；
4. `docs/05_工程详细设计.md`、`06_字符集与制作规划.md`：制作落实；
5. `docs/07_测试与验收.md`、`08_授权与发布.md`、`09_对抗式自审.md`：品质与发行；
6. `tables/字符集与测试计划.xlsx`：可维护字符规划、测试用例和需求追溯；
7. `config/HK_Poster_Heavy.yaml`：可填入通用字体生成提示词的项目专属配置；
8. `specimens/港_电影海报视觉概念.png`：此前生成的“港”字概念效果图。

## 两个关键说明

- **字体本体与海报视觉效果分离。** 霓虹、荧光描边、颗粒、雨夜反射属于应用样张的图形处理，不视为 OTF/TTF 字形轮廓的必要组成。
- **状态不可冒充。** 这份资料完成了文字上的设计规划；没有生成 Glyph 轮廓、UFO 工程、字距数据或 OTF/TTF/WOFF2 成品，也没有执行真实字体构建、安装或兼容性测试。表格中的测试状态均为 `NOT_RUN`。

## 与初始方案相比的整理

原方案以简体字优先。为了更贴近香港电影海报的地区文字使用习惯，**本次打包版将繁体中文（香港地区字形）设为视觉主基线**，简体中文保留为可选扩展；这一调整为设计建议，尚待项目所有者确认。英文/数字同步设计。
