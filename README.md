# 港映重黑｜香港电影海报风格粗字体设计资料包

**文档基线：v1.1 · 2026-10-24（Wave 0 试制后）**  
**项目代号：HK Poster Heavy / 港映重黑（暂定名）**
**交付性质：设计文档 + Wave 0 字体工程（可构建的 OTF/TTF/WOFF2），**尚未**达到可发布状态。**

本资料包将对话中的香港电影海报风格粗字体方案整理为可用于后续制作的需求、基本设计、详细设计、测试与发布资料；
并在 Wave 0 阶段补上了实际字形、字体工程、测试与样张。设计将 1980—1990 年代香港商业电影海报的标题张力转化为可执行的字形设计规则，同时避免直接复刻任何具体电影片名字形。

## 两个关键说明

- **字体本体与海报视觉效果分离。** 霓虹、荧光描边、颗粒、雨夜反射属于应用样张的图形处理，不视为 OTF/TTF 字形轮廓的必要组成。
- **状态不可冒充。** 已有真实字形源、UFO master、可构建的 OTF/TTF/WOFF2、可执行的 UT/IT/ST 与样张；
  但 **macOS/浏览器平台测试未执行**；字体二进制已按 **SIL OFL 1.1** 授权（自动骨架层另受 Arphic Public License 约束，见 `OFL.txt` / `ARPHICPL.TXT`）——
  表格中未执行的一律保持 `NOT_RUN`，不因“文档已完成”而标 PASS。

## 与初始方案相比的整理

原方案以简体字优先。为了更贴近香港电影海报的地区文字使用习惯，**本次打包版将繁体中文（香港地区字形）设为视觉主基线**，简体中文保留为可选扩展；这一调整为设计建议，尚待项目所有者确认。英文/数字同步设计。
