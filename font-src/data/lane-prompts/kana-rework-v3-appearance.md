| 风格语义 | 字形实现方向 |

| 规则 ID | 规则 | 对假名的含义 |
|---|---|---|
| GLY-001 | 横竖笔画维持统一视觉重量 | 假名各笔重量一致，不许某根特别细 |

====================================================================
二、现在假名为什么不属于这个家族（对照证据）
====================================================================

本字体的**汉字**已经有海报味，做法是：

```python
g.hbar(...)                  # 横 = 硬边矩形
g.vbar(...)                  # 竖 = 硬边矩形
g.diag(...)                  # 撇捺 = 斜切边矩形
g.dot(158, 700, w=94, h=126, slant=26)   # 点 = 斜切平行四边形  ← 海报签名
```

`slant=26` 的斜切平行四边形点（港的氵、影的彡、無的四点、夜的捺）
就是「少量端点倾切 / 外沿微伸」在汉字里的落地方式。

**假名的问题**：

1. **平假名**：曲笔用 `_band()` 折线加粗成**圆转角**的管子
   （原 docstring：「端面平切，转折处圆滑…转角处补一段圆弧」）。
   → 违反 GLY-002「外角以清晰硬折为主」。
2. **两条 lane 的共性**：浊点 / 半浊点 / 点画**没有统一到汉字的斜切语言**。
3. **重量**：假名/汉字 墨量比 0.469，低于所有日文黑体的 0.48–0.57（这个在上一轮处理）。

====================================================================
三、任务 A（平假名 lane 重点）：`_band` 改成「外角硬、内角开孔」
====================================================================

**目标**：曲线的**外侧转角**变成硬折（两条偏移边的交点），
**内侧转角**开孔（不交叉、不自交）。端面**保持平切**（垂直于中心线）不变。

算法（自洽即可，实现方式自定，但结果必须满足下面 4 条）：

1. 逐段沿法线左右各偏移 `w/2`，得到左右两条偏移线。
2. 每个顶点求左右两条偏移线的**交点**（miter 点）。
3. **外角（凸转角）**：用 miter 点 → **硬折**。
   - miter 长度封顶：若从拐点到 miter 点的距离 > `2.5 × (w/2)`，改为**斜切（bevel）**，
     避免尖刺（尖刺会在 48px 下变成毛刺，违反 GLY-006）。
4. **内角（凹转角）**：两段偏移线会相交 → 直接**连两个偏移端点**（bevel），
   形成 V 形内凹，就是设计资料说的「内角必要时适度开孔」。
   - 开孔过大时（锐角），在开孔处**再补一小段**（微开孔），保持识别特征。
5. **输出的带必须是简单闭合多边形（不自交）** ——
   `hkbuild` 会对笔画做并集，自交会产生非法轮廓。
   改造后**必须自查**：每个字形的轮廓无自交（`check_glyphs.py` 会报 FAIL）。

**不许做的事**：
- 不许改中心线坐标（那是字形，用户要求保持）；
- 不许为了"看起来更硬"去挤压字面或整体倾斜（docs/02 偏差 D、docs/03 §1 禁止无差别挤压/倾斜）；
- 不许把曲线的所有转角都做成尖刺（miter 封顶那条就是为此）。

====================================================================
四、任务 B（两条 lane 都做）：端点斜切，统一到汉字的语言
====================================================================

1. **浊点 / 半浊点**（`DAKU` / `HAND` 与预组合形里的同一枚记号）：
   改成**斜切平行四边形**，与汉字 `g.dot(..., slant=26)` 同语言、同角度档。
   全字族统一（GLY-004）——同一枚记号在任何字里的形状必须一致。
2. **点画 / 短撇**（う え お 的点、ぬ ね 的点等）：
   同样用带 `slant` 的点/短撇，**不要用普通圆头**。
3. **GLY-003 约束**：斜切**只许**用在点/短撇/记号这类**不影响结构**的位置。
   **主笔（横竖撇捺）的识别笔画不许随意斜切。**
4. 汉字的 slant 取值参考 `font-src/src/hkposter-cjk-core.py`：
   主流是 `slant=26`，也有 14/16/18/20/−14 —— 也就是说**倾切角度是有分档的**，
   不是一刀切。假名沿用同一套分档（点用 26，短撇可用 14~20）。

====================================================================
五、任务 C：字重 —— 在**新外观**上迭代到墨量比 0.55
====================================================================

等任务 A、B 做完再开始迭代（顺序不能反）。

起点仍是 `W_MAIN 110 / W_SEC 100 / W_THIN 90 / W_DOT 100`，
然后迭代：

```
python font-src/scripts/check_kana_size.py --font font-src/dist/HKPoster-Heavy.ttf
```

看 `假名/汉字 墨量比` 那一行，**落到 0.54..0.56** 为止（最多 6 轮）。
硬角改造后墨量会变，起始值可能需要再调。

⚠️ 加粗 + 硬角之后**内白会被挤掉**：
* 逐字看**内白（counter）还在不在**；
* 小假名（っ ッ ゃ ャ 等）和 2–3 画的字（つ フ へ ン ウ エ オ ら し す そ ま み も ぬ ね の は ひ ふ ほ り る れ ろ わ を）最容易糊；
* 糊了就**该字单独降一档**（W_MAIN→W_SEC），不许全局回退；
* GLY-006：48px 缩印后内白不得完全消失。

====================================================================
六、任务 D：「中宫凝聚 / 明确顿挫」的落点
====================================================================

docs/02 要求「中宫凝聚、轮廓有拔势和明确顿挫」。
**这一条不需要额外挤压**——硬角 + 统一重量自然带来「顿挫」，
而「中宫凝聚」指的是**内白收紧**，由硬角与重笔画自然产生。

**不许**：为了「更凝聚」去手工缩内白（那会破坏字形）。
如果某个字的内白在改造后仍过大而显得松垮，
用**加粗该字**解决（该字单独提一档），而不是缩放骨架。

八、自检（不准省）
====================================================================

改造后跑完那 6 条命令之外，**必须**做：

1. **混排目视**（最重要）—— 这是判断「是不是一个家族」的唯一办法：

```
python font-src/scripts/render_glyph_sheet.py --font font-src/dist/HKPoster-Heavy.ttf --text "香港映画 あいうえお カタカナ っゃゅょ" --size 300 --out font-src/reports/kana-<你的 lane>-poster.png
```

用 read 工具打开 PNG，逐条对照 `docs/02`：
* 假名和汉字在**同一行**里，是不是同一个重量档、同一种端点语言？
* 曲线的外角有没有变成硬折？内角有没有开孔而不是糊死？
* 点画 / 浊点有没有跟汉字的点一样是斜切平行四边形？
* 有没有哪个字的内白被挤没了？

2. **与参照对照**（参照只用来确认骨架与识别性，**不描轮廓**）：

```
python font-src/scripts/check_kana_fidelity.py --font font-src/dist/HKPoster-Heavy.ttf --reference E:/hkposter-refs/MPLUS1p-Black.ttf --out font-src/reports/kana-fidelity-<你的 lane>.json --sheet font-src/reports/kana-fidelity-<你的 lane>.png
```

3. **48px 缩印**（GLY-006）：

```
python font-src/scripts/render_glyph_sheet.py --font font-src/dist/HKPoster-Heavy.ttf --text "あいうえおカタカナ" --size 48 --out font-src/reports/kana-<你的 lane>-48.png
```

看内白在 48px 下还在不在。

4. **尺寸与落位门禁**：

```
python font-src/scripts/check_kana_size.py --font font-src/dist/HKPoster-Heavy.ttf
```

（lane 的子集构建会误报「缺字 96 个」「汉字中位 = N/A」，**只看你负责的那几行**：
`假名/汉字 墨量比`、`小假名比例`、`超出 em 边界`、`假名/汉字 字高比`。）

不满意就改 → 重新生成 → 重新渲染 → 再看（最多 8 轮）。
