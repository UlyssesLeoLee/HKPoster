二、任务 A：把假名加粗到「假名/汉字 墨量比 = 0.55」
====================================================================

现状（本字体，em=1000）：

```
[kana-size] 假名/汉字 墨量比 = 0.469   (目标 0.54..0.56)
```

**做法**：只提高**笔画权重**档位，不动笔画走向、不动骨架、不动字面框。

| | 现值 | 起始值 | 说明 |
|---|---|---|---|
| W_MAIN | 92 | **110** | 主笔（横、竖、大弧） |
| W_SEC | 84 | **100** | 次级笔画 |
| W_THIN | 76 | **90** | 细笔（内横、辅助撇） |
| W_DOT | 84 | **100** | 点（浊点、点画） |

起始值是按「墨量 ∝ 笔画宽度」估的（0.469 × 1.196 ≈ 0.56），
但并集会吃掉一部分增量，**所以要迭代**：

```
python font-src/scripts/check_kana_size.py --font font-src/dist/HKPoster-Heavy.ttf
```

看 `假名/汉字 墨量比` 那一行，**迭代到 0.54..0.56**（最多 6 轮），
每轮改权重 → 重新生成 UFO → 重新构建 → 重新量。

⚠️ 加粗后必须**目视检查**（见第四节）：
笔画变粗会把**内白（counter）挤掉**，小假名和 2–3 画的字最容易糊成一团。
如果某个字加粗后内白消失或粘连，**该字单独降一档**（W_MAIN→W_SEC），不要全局回退。

三、任务 B：三个尺寸/越框问题
====================================================================

**B1. ゥ (U+30A5) 太小**（片假名 lane 负责）
现状字高 356，只占全尺寸片假名的 **0.47**。标准小假名应在 **0.65..0.78**
（参照 M PLUS 1p / Noto Sans JP 的 ァ ッ ャ 都是这个量级）。
→ 放大到全尺寸片假名字高的 **0.68..0.72 倍**，保持**水平居中（中心 x=500）+ 贴基线（底边 y≈40）**，
只改大小、不改笔画拆法。

**B2. ゖ (U+3096) 卡在边界**（平假名 lane 负责）
现状 416，占全尺寸 0.55（门槛就是 0.55）。
→ 放大到 **0.65..0.72 倍**，同样保持居中 + 贴基线。

**B3. ぜ (U+305C) 的墨迹越出 em**（平假名 lane 负责）
现状成品实测 `ぜ` 墨迹框 = **x −48..931**，左缘超出 em 48 单位，正文里会跟前一字撞。

> **标准解法：把 ぜ 的「せ」底座横向收窄，给浊点腾出右上角。**
> 实测 Yu Gothic Bold：せ 本身 x 44.4..936.5（宽 892），而 ぜ 是 x 35.2..988.8（宽 954）——
> 浊点把右边撑出去了，**同时底座必然比单独的 せ 更窄**。
> 这就是 ぜ/げ/ば 那一族「浊点让位」的标准解法。

做法：
1. 把 ぜ 的 せ 底座**横向收窄**（只收窄，**高度与笔画权重不动**），
   收到「浊点落进右上角后不与底座相交」为止；
2. 浊点保持在 em 的右上角；
3. 收窄后 ぜ 的墨迹必须完整落在 x 0..1000、y −120..880 之内，总宽 ≤ 940。

> ⚠️ 「保持原有状态」指的是**骨架的形**，不是「一个字都不能动」——
> **参照字体的 ぜ 本身就是收窄的底座**，照参照做不是偏离标准。
> 平假名 lane 的 `dev` 上已有上一轮的实现（`56ff745 修 ぜ 的越框（底座收窄给浊点让位）`），
> 你可以在其基础上继续，但**必须用新的权重重新验证**。
