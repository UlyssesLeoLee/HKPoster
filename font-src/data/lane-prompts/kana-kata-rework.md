渲染出来是 `.notdef` 空心框 —— 在日文正文里直接读不出来：

| ・ | U+30FB | uni30FB | 片假名中点（居中点，advance 1000） |
| ヿ | U+30FF | uni30FF | 片假名双字（ノ + 丶，"koto" 连字） |

注意区分：

* **小假名**（ァィゥェォッャュョヮヵヶ）：字形是**另画的**，笔画更少更紧凑。
* **浊点组合形**（ヴ ヷ ヸ ヹ ヺ）：**全尺寸**，是在对应全尺寸字上加浊点/半浊点，
  不是小字。
* **゠**：两条平行的长横杠（double hyphen）。
* **・**：居中的圆点（不是句点）。
* **ヿ**：由 ノ 和 丶 两笔组成的连字形。

**⚠️ 小假名落位规则（2026-10-25 集成方实测订正，以本条为准）**

规格初稿写的是「小假名位于 em 的**右上区域**」，**那是错的**。
实测参照字体 Yu Gothic Bold（em=2048）：

| 字 | x 范围 | 中心 x | y 范围 | 字高 | 占全尺寸 |
|---|---|---:|---|---:|---:|
| ァ(小) | 395..1714 | 1054 | -92..1151 | 1243 | 0.70 |
| ッ(小) | 375..1688 | 1032 | -119..1150 | 1269 | 0.71 |
| ャ(小) | 324..1706 | 1015 | -105..1239 | 1344 | 0.76 |

**参照字体的小假名是「水平居中 + 贴基线」**，不是右上区域：
中心 x 落在 em 中心附近（1015..1054，em 中心 1024），底边都在基线上。

本字体的落位规则（**只管落位，形状按标准形另画**）：

1. **水平居中**：墨迹外接框中心 x = **500**。
2. **贴基线**：墨迹外接框底边 y ≈ **40**（本字体全尺寸片假名墨迹底部离基线 39）。
3. **大小**：小假名字高 = 全尺寸片假名字高的 **0.65..0.78**。
4. **只改位置，不改形状** —— 笔画清单与拆法一个字都不要动。

> 为什么这条要单列：**同一个字体里两种落法会自相矛盾**
> （把 ァィゥェォャュョ 放右上、而 ッ 放居中，两者并排就不协调）。
> 用户的硬要求是「整体字形必须还保持原有状态」——「原有」就是标准假名的形与位。

小假名的 advance = **1000**（与全尺寸假名一致）。

二、任务 B：把全尺寸片假名放大到与汉字同族（当前明显偏小）
====================================================================

实测数据（本字体，em=1000）：

| | 本字体 | 参照（Yu Gothic Bold） |
|---|---|---|
| 汉字字高中位 | **796**（港 830） | 928 |
| 片假名字高中位 | **601** | 807 |
| 假名/汉字 字高比 | **0.756** | 0.87 |
| 假名/汉字 墨量比 | 0.66 | 0.53 |

**结论：片假名不是「太轻」，是「太小」。**
当前笔画相对高度（92/601 ≈ 0.153）已经比汉字（96/830 ≈ 0.116）还重，
所以不需要加重，需要**放大字面**、让笔画相对变细，比例才回到家族关系里。

**做法（照做，不要自由发挥）**：

1. **只缩放中心线坐标，不动笔画权重**。
   笔画权重保持 **W_MAIN=92 / W_SEC=84 / W_THIN=76 / W_DOT=84 不变**。
2. 缩放系数 **×1.30**，围绕**该字自身的墨迹外接框中心**缩放，
   缩放后把该字的墨迹外接框**中心重新对到 (500, 400)** ——
   x=500 是 em 的水平中心，y=400 是与汉字对齐的光学中心（现有假名就以 y=400 为中线）。
   （例外：**ー / ヽ / ヾ / ゛ / ゜ / 浊音符** 这类本身没有「上下分布」的字，
   以及 ッ 这类本来就在下方的字，按第三节的目视结果微调。）
3. 新补的小假名**直接按最终尺寸画**（不要先画大再缩），
   目标是它的字高约为全尺寸片假名的 **0.70 倍**。

**目标区间（逐字自检用）**：

- 全尺寸片假名：墨迹外接框 **高度 760..880 单位**，**宽度 560..900 单位**；
- 假名字高 / 汉字字高（中位）落在 **0.88 ~ 0.95**。

三、怎么自检（不准省）
====================================================================

参照字体在系统上：**C:/Windows/Fonts/YuGothB.ttc**（Yu Gothic Bold，标准日文骨架）。

1. 生成 UFO：

    python font-src/src/hkposter-kana-kata.py

2. recipe ↔ UFO 同步、字形 UT：

    python font-src/scripts/check_recipes.py --recipes font-src/src/hkposter-kana-kata.py
    python font-src/scripts/check_glyphs.py --sources font-src/masters/hkposter-kana-kata.ufo

3. 构建 + 成品校验：

    python font-src/scripts/build_font.py --sources font-src/masters/hkposter-kana-kata.ufo --out font-src/dist
    python font-src/scripts/verify_font.py --font font-src/dist/HKPoster-Heavy.ttf --sources font-src/masters/hkposter-kana-kata.ufo

4. **假名保真度检查**（集成方新增的工具，硬门禁是「缺字」）：

    python font-src/scripts/check_kana_fidelity.py --font font-src/dist/HKPoster-Heavy.ttf --reference C:/Windows/Fonts/YuGothB.ttc --out font-src/reports/kana-fidelity-kata.json --sheet font-src/reports/kana-fidelity-kata.png

   * **缺字 = 硬门禁**：这个 lane 交出时，片假名区 U+30A0..U+30FF 必须 **0 缺字**。
   * 骨架 IoU 是**软信号**（同一字换字重都会掉到 0.55 中位），
     它的用途是**排序**：分数最低的几个字你要重点目视复核。

5. **目视对照（不能省，最重要的一步）**：
   用 read 工具打开 `font-src/reports/kana-fidelity-kata.png` ——
   左边是本字体、右边是参照字体，逐字对比：

   - 骨架还是那个字吗？（不是「另一个假名」）
   - 补的 20 个字位置对吗？（小假名在右上、ッ 居中偏下、・ 居中）
   - 新字形和原有 46 个片假名观感一致吗？

   再渲染一张混排图，确认假名和汉字在**同一行里大小协调**：

    python font-src/scripts/render_glyph_sheet.py --font font-src/dist/HKPoster-Heavy.ttf --text "アイウエオ漢字ひらがなッャュョヴヷ・゠" --size 260 --out font-src/reports/kana-kata-mix.png

   然后 **用 read 工具打开这张 PNG 看**。

6. 不满意就改 recipe → 重新生成 → 重新渲染 → 再看（最多 6 轮）。

====================================================================
四、设计取舍（与原有 recipe 一致，不要推翻）
====================================================================

* 字面框：假名 advance 固定 1000。
* 笔画权重四档不变：**主 92 / 次 84 / 细 76 / 点 84**。
* 曲线笔用 `_band()` 折线加粗成闭合轮廓：端面平切，转折处圆弧过渡。
* 所有墨迹收在 x 60..940 / y 0..820 之内（与汉字同框）。
* 字形之间不互相粘连（GLY-005）。
* 同一部件在全字族复用同一套坐标与笔画拆法（docs/03 GLY-004）。
* 禁止逐字机械挤压或倾斜（docs/02 偏差 D）。

**最重要的约束**：放大假名时**只能改坐标，不能改骨架**。
不许为了让 IoU 分数好看去改笔画走向 —— IoU 只是排序信号，
真正的判据是「看得出是哪个假名」。
