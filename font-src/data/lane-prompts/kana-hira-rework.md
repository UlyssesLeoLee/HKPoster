一、任务 A：补齐 16 个缺失的平假名（**硬门禁，当前会渲染成豆腐块**）
====================================================================

实测（读成品 TTF 的 cmap）确认以下 16 个码位**根本不在字体里**，
渲染出来是 `.notdef` 空心框 —— 在日文正文里直接读不出来：

| 字符 | 码位 | 字形名 | 说明 |
|---|---|---|---|
| ぁ | U+3041 | uni3041 | 小假名 あ |
| ぃ | U+3043 | uni3043 | 小假名 い |
| ぅ | U+3045 | uni3045 | 小假名 う |
| ぇ | U+3047 | uni3047 | 小假名 え |
| ぉ | U+3049 | uni3049 | 小假名 お |
| っ | U+3063 | uni3063 | 小假名 つ（**日文最高频假名之一**） |
| ゃ | U+3083 | uni3083 | 小假名 や |
| ゅ | U+3085 | uni3085 | 小假名 ゆ |
| ょ | U+3087 | uni3087 | 小假名 よ |
| ゎ | U+308E | uni308E | 小假名 わ |
| ゔ | U+3094 | uni3094 | う + 浊点（**全尺寸**，不是小假名） |
| ゕ | U+3095 | uni3095 | 小假名 か |
| ゖ | U+3096 | uni3096 | 小假名 け |
| ゗ | U+3097 | uni3097 | ゝ + 斜杠（读作 ヨリ） |
| ゘ | U+3098 | uni3098 | ゝ + 浊点 |
| ゟ | U+309F | uni309F | ゝ + 半浊点 |

**小假名不是「把全尺寸字缩小的复制品」**，它们的字形是**另画的**：
笔画更少、更紧凑、起收笔更直接。而且位置也不同 ——
ぁぃぅぇぉゃゅょゎゕゖ 位于 em 的**右上区域**；
っ 横向**居中**、纵向偏下（它是「つ」的小写，不是右上角的小字）。
具体位置以参照字体为准（见第三节的自检方法），不要凭印象。

按 Unicode 惯例，小假名的 advance = **1000**（与全尺寸假名一致），
只有浊音符 U+3099 / U+309A 是 advance = 0 的零宽合记号（已存在，不要动）。

二、任务 B：把全尺寸假名放大到与汉字同族（当前明显偏小）
====================================================================

实测数据（本字体，em=1000）：

| | 本字体 | 参照（Yu Gothic Bold） |
|---|---|---|
| 汉字字高中位 | **796**（港 830） | 928 |
| 平假名字高中位 | **586** | 872 |
| 片假名字高中位 | 601 | 807 |
| 假名/汉字 字高比 | **0.736** | 0.94 |
| 假名/汉字 墨量比 | 0.74 | 0.53 |

**结论：假名不是「太轻」，是「太小」。**
当前假名的笔画相对高度（92/586 ≈ 0.157）已经比汉字（96/830 ≈ 0.116）还重，
所以不需要加重，需要**放大字面**、让笔画相对变细，比例才回到家族关系里。

**做法（照做，不要自由发挥）**：

1. **只缩放中心线坐标，不动笔画权重**。
   笔画权重保持 **W_MAIN=92 / W_SEC=84 / W_THIN=76 / W_DOT=84 不变**。
2. 缩放系数 **×1.35**，围绕**该字自身的墨迹外接框中心**缩放，
   缩放后把该字的墨迹外接框**中心重新对到 (500, 400)** ——
   x=500 是 em 的水平中心，y=400 是与汉字对齐的光学中心（现有假名就以 y=400 为中线）。
   （例外：**ー / ゝ / ゞ / ゛ / ゜ / 浊音符** 这类本身没有「上下分布」的字，
   以及 っ 这类本来就在下方的字，按第三节的目视结果微调。）
3. 新补的小假名**直接按最终尺寸画**（不要先画大再缩），
   目标是它的字高约为全尺寸假名的 **0.70 倍**。

**目标区间（逐字自检用）**：

- 全尺寸平假名：墨迹外接框 **高度 760..880 单位**，**宽度 560..900 单位**；
- 假名字高 / 汉字字高（中位）落在 **0.88 ~ 0.95**。

三、怎么自检（不准省）
====================================================================

参照字体在系统上：**C:/Windows/Fonts/YuGothB.ttc**（Yu Gothic Bold，标准日文骨架）。

1. 生成 UFO：

    python font-src/src/hkposter-kana-hira.py

2. recipe ↔ UFO 同步、字形 UT：

    python font-src/scripts/check_recipes.py --recipes font-src/src/hkposter-kana-hira.py
    python font-src/scripts/check_glyphs.py --sources font-src/masters/hkposter-kana-hira.ufo

3. 构建 + 成品校验：

    python font-src/scripts/build_font.py --sources font-src/masters/hkposter-kana-hira.ufo --out font-src/dist
    python font-src/scripts/verify_font.py --font font-src/dist/HKPoster-Heavy.ttf --sources font-src/masters/hkposter-kana-hira.ufo

4. **假名保真度检查**（集成方新增的工具，硬门禁是「缺字」）：

    python font-src/scripts/check_kana_fidelity.py --font font-src/dist/HKPoster-Heavy.ttf --reference C:/Windows/Fonts/YuGothB.ttc --out font-src/reports/kana-fidelity-hira.json --sheet font-src/reports/kana-fidelity-hira.png

   * **缺字 = 硬门禁**：这个 lane 交出时，平假名区 U+3041..U+309F 必须 **0 缺字**。
   * 骨架 IoU 是**软信号**（同一字换字重都会掉到 0.55 中位），
     它的用途是**排序**：分数最低的几个字你要重点目视复核。

5. **目视对照（不能省，最重要的一步）**：
   用 read 工具打开 `font-src/reports/kana-fidelity-hira.png` ——
   左边是本字体、右边是参照字体，逐字对比：

   - 骨架还是那个字吗？（不是「另一个假名」）
   - 补的 16 个字位置对吗？（小假名在右上、っ 居中偏下）
   - 新字形和原有 46 个假名观感一致吗？

   再渲染一张混排图，确认假名和汉字在**同一行里大小协调**：

    python font-src/scripts/render_glyph_sheet.py --font font-src/dist/HKPoster-Heavy.ttf --text "あいうえお漢字カタカナっゃゅょ" --size 260 --out font-src/reports/kana-hira-mix.png

   然后 **用 read 工具打开这张 PNG 看**。

6. 不满意就改 recipe → 重新生成 → 重新渲染 → 再看（最多 6 轮）。

====================================================================
四、设计取舍（与原有 recipe 一致，不要推翻）
====================================================================

* 字面框：假名 advance 固定 1000。
* 笔画权重四档不变：**主 92 / 次 84 / 细 76 / 点 84**。
* 曲线笔用 `_band()` 折线加粗成闭合轮廓：端面平切，转折处圆弧过渡。
* 所有墨迹收在 x 60..940 / y 0..820 之内（与汉字同框）。
* 字形之间不互相粘连（GLY-005）。
* 同一部件在全字族复用同一套坐标与笔画拆法（docs/03 GLY-004）。
* 禁止逐字机械挤压或倾斜（docs/02 偏差 D）。

**最重要的约束**：放大假名时**只能改坐标，不能改骨架**。
不许为了让 IoU 分数好看去改笔画走向 —— IoU 只是排序信号，
真正的判据是「看得出是哪个假名」。
